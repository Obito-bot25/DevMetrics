An architectural cyber-brutalist web application designed to evaluate a developer's autonomy quotient vs. AI dependency. Begins as a serious, authoritative software engineering benchmark and concludes with an unexpected satirical **Certified Cuck Coder** dossier.

## Features

- **Professional Camouflage**: Authentic developer competency framework landing page that conceals the satire until assessment completion.
- **Multi-Phase Interactive Audit**:
  - Phase 1: Identity & Engineering Seniority tier.
  - Phase 2: AI Tool Stack Matrix (Cursor, Claude, Windsurf, Copilot, DeepSeek, Ollama, Gemini, Antigravity, etc.).
  - Phase 3: Telemetry questionnaire with interactive dropdown triggers and click-to-autofill options.
- **Surgical Roast Engine**: Deterministic telemetry engine calculating AI dependency percentages (80%–99.9%), personalized badges, coping mechanisms, and titles.
- **High-Resolution Dossier Generation**: Client-side 2x PNG rendering (`html-to-image`) with verified cryptographic seal and QR code.
- **Responsive Cyber Brutalism**: Strict monochrome paper palette (`#F7F7F9` / `#0A0A0A`) with electric violet and acid lime accents, fluid typography down to 320px mobile screens, and accessibility focus states.

## Tech Stack

- **Framework**: React 19 + Vite 8
- **Styling**: Vanilla CSS with architectural Cyber Brutalism tokens
- **Icons**: Lucide React
- **Export & Effects**: `html-to-image`, `canvas-confetti`
- **Linting & Testing**: `oxlint`, Node.js Native Test Runner

## Getting Started

### Install Dependencies
```bash
npm install
```

### Run Locally (Development Server)
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### Run Automated Tests
```bash
npm test
```

### Run Linter
```bash
npm run lint
```

### Production Build
```bash
npm run build
```
The compiled static assets will be output to the `dist/` directory.
